# DeepL CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an agent-friendly `deepl` CLI (`deepl translate <text> --to <LANG>` + `deepl list`) that translates any text via DeepL API with minimal, pipe-friendly I/O and reliable auth, as a Deno/TypeScript single-binary in `bin/deepl`.

**Architecture:** Single-file `typescript/deepl/deepl.ts` using native `fetch` (no `deepl-node` dep — `ponytail: fetch + 30 lines covers the POST, add deepl-node only if retries/batching need it`). Parses args manually (no clap/parcel), resolves `DEEPL_API_KEY` via `--api-key` > `Deno.env` > `typescript/deepl/.env` fallback (never `pass`), auto-detects `api-free.deepl.com` vs `api.deepl.com` via `:fx` suffix, calls `POST /v2/translate` and `GET /v3/languages`, outputs plain text by default and `--json` for machine parsing. Compiles via `typescript/release.sh` (`deno compile -o bin/deepl -A`).

**Tech Stack:** Deno 2.x, TypeScript 5, `fetch` (built-in), `Deno.*` APIs only. Optional `deno.json` imports — none required for MVP (avoid `lib-result`/`npm:deepl-node` per ladder rung 3-5). If you add `lib-result`, pin via `deno.json` imports.

## Global Constraints

- Runtime: Deno >=2.0 (uses `Deno.args`, `Deno.env`, `Deno.readTextFile`, `Deno.stdin`, `Deno.stat`, `fetch`).
- Naming: binary `deepl` (no alias `translate` — avoids coreutils collision), source at `typescript/deepl/deepl.ts`, compiled to `bin/deepl`.
- Auth: precedence `--api-key` flag > `DEEPL_API_KEY` env var (process env merged with `typescript/deepl/.env` if present) > error with hint; never log key; never invoke `pass show deepl/api-key` automatically.
- Endpoint: `https://api-free.deepl.com` if key ends with `:fx` else `https://api.deepl.com`; endpoint is derived, not configurable (YAGNI — add `--api-url` only if self-hosted use-case appears).
- Characters: free plan 500K/month — all verification must use <100-char smoke inputs.
- No interactive prompts in pipe/CI mode — `--help` is the only user-facing help; errors go to stderr, translations to stdout.
- Deno permissions: compiled with `-A` via `release.sh`; `deno.json` tasks use `--allow-env --allow-net --allow-read --allow-write` (minimal that covers auth + net + `--input-file`/`--output-file` + `.env`).
- Repo conventions: `typescript/*/deno.json` with `dev`/`compile` tasks, `make-signature` not needed for TS, `check-deps` not needed for Deno.

  ```typescript
  async function loadDotEnv(): Promise<void> {
    // ponytail: .env is relative to script path (~/scripts/typescript/deepl/.env), not CWD
    try {
      const scriptDir = new URL(".", import.meta.url).pathname;
      const envPath = `${scriptDir}.env`;
      const text = await Deno.readTextFile(envPath);
      for (const line of text.split("\n")) {
        const trimmed = line.trim();
        if (!trimmed || trimmed.startsWith("#")) continue;
        const eq = trimmed.indexOf("=");
        if (eq === -1) continue;
        const k = trimmed.slice(0, eq).trim();
        const v = trimmed.slice(eq + 1).trim().replace(/^["']|["']$/g, "");
        if (k === "DEEPL_API_KEY" && !Deno.env.get(k)) {
          Deno.env.set(k, v);
        }
      }
    } catch {
      // no .env is fine
    }
  }

  function resolveApiKey(flagKey?: string): string {
    if (flagKey) return flagKey;
    const envKey = Deno.env.get("DEEPL_API_KEY");
    if (envKey) return envKey.trim();
    console.error("ERROR: DEEPL_API_KEY not set. Use --api-key <key> or set DEEPL_API_KEY env var or typescript/deepl/.env");
    Deno.exit(2);
  }

  function resolveBaseUrl(key: string): string {
    return key.endsWith(":fx") ? "https://api-free.deepl.com" : "https://api.deepl.com";
  }
  ```

### Task 3: `deepl translate` core — call `POST /v2/translate`

**Files:**

**Interfaces:**

- [ ] **Step 1: Implement `translateTexts` (fetch, no deepl-node)**
  ```typescript
  type TranslateOpts = { sourceLang?: string; targetLang: string; context?: string; formality?: string; showBilled?: boolean };
  type Translation = { text: string; detected_source_language: string; billed_characters?: number; model_type_used?: string };

  async function translateTexts(texts: string[], opts: TranslateOpts, apiKey: string, baseUrl: string): Promise<Translation[]> {
    const body: Record<string, unknown> = {
      text: texts,
      target_lang: opts.targetLang.toUpperCase(),
    };
    if (opts.sourceLang) body.source_lang = opts.sourceLang.toUpperCase();
    if (opts.context) body.context = opts.context;
    if (opts.formality) body.formality = opts.formality;
    if (opts.showBilled) body.show_billed_characters = true;
    // model_type omitted unless --model is added later (YAGNI)

    const res = await fetch(`${baseUrl}/v2/translate`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": `DeepL-Auth-Key ${apiKey}`,
      },
      body: JSON.stringify(body),
    });

    if (!res.ok) {
      const trace = res.headers.get("X-Trace-ID") ?? "";
      const errBody = await res.text().catch(() => "");
      let msg = `DeepL API ${res.status} ${res.statusText}`;
      if (errBody) msg += `: ${errBody.slice(0, 500)}`;
      if (trace) msg += ` (X-Trace-ID: ${trace})`;
      // map common codes to exit hints
      if (res.status === 403) msg += " — check DEEPL_API_KEY and :fx vs pro endpoint";
      if (res.status === 456) msg += " — quota exceeded (free 500K/mo)";
      console.error(`ERROR: ${msg}`);
      Deno.exit(res.status === 456 ? 3 : res.status === 403 ? 2 : 2);
    }
    const data = await res.json() as { translations: Translation[] };
    return data.translations;
  }
  ```

- [ ] **Step 1: Implement `resolveInputTexts`**
  ```typescript
  async function resolveInputTexts(positional: string[], inputFile?: string): Promise<string[]> {
    const hasPositional = positional.length > 0;
    const hasFile = !!inputFile;
    const isPipe = !Deno.stdin.isTerminal();

    if (hasPositional && hasFile) {
      console.error("ERROR: <text> args and --input-file are mutually exclusive");
      Deno.exit(1);
    }
    if (hasFile && isPipe) {
      console.error("ERROR: --input-file and piped stdin are mutually exclusive");
      Deno.exit(1);
    }
    if (hasPositional && isPipe) {
      console.error("ERROR: <text> args and piped stdin are mutually exclusive");
      Deno.exit(1);
    }
    if (hasFile) {
      const content = await Deno.readTextFile(inputFile!);
      return [content]; // one unit, preserve newlines
    }
    if (hasPositional) return positional;
    if (isPipe) {
      const buf = await new Response(Deno.stdin.readable).text();
      const trimmed = buf.trim();
      if (!trimmed) { console.error("ERROR: no input from stdin"); Deno.exit(1); }
      return [buf];
    }
    console.error("ERROR: no input — provide <text> args, --input-file <path>, or pipe stdin");
    Deno.exit(1);
  }
  ```
  Also enforce 128 KiB check: `if (new TextEncoder().encode(texts.join("\n")).length > 128*1024) console.error("WARN: request near 128KiB limit — DeepL may reject")`

- [ ] **Step 1: Implement `renderOutput`**
  ```typescript
  async function renderOutput(translations: Translation[], opts: { json: boolean; verbose: boolean; outputFile?: string }) {
    let out: string;
    if (opts.json) {
      out = JSON.stringify({ translations }, null, 2) + "\n";
    } else {
      out = translations.map(t => t.text).join("\n") + "\n";
      if (opts.verbose) {
        const meta = translations.map(t => `[detected:${t.detected_source_language}${t.billed_characters ? ` billed:${t.billed_characters}` : ""}${t.model_type_used ? ` model:${t.model_type_used}` : ""}]`).join(" ");
        console.error(meta);
      } else {
        // always emit concise detected lang to stderr for LLM info without polluting stdout
        const detected = translations.map(t => t.detected_source_language).join(",");
        console.error(`[detected: ${detected}]`);
      }
    }
    if (opts.outputFile) {
      await Deno.writeTextFile(opts.outputFile, out);
    } else {
      await Deno.stdout.write(new TextEncoder().encode(out));
    }
  }
  ```
  `showBilled` should be sent only when `--verbose` or `--json` (since it affects billing char count visibility, not translation).

- [ ] **Step 1: Implement `listLanguages`**

  ```typescript
  async function listLanguages(apiKey: string, baseUrl: string, jsonMode: boolean) {
    const endpoints = [
      `${baseUrl}/v3/languages?resource=translate_text`,
      `${baseUrl}/v2/languages`,
    ];
    let data: unknown = null;
    let lastErr = "";
    for (const url of endpoints) {
      const res = await fetch(url, { headers: { "Authorization": `DeepL-Auth-Key ${apiKey}` } });
      if (res.ok) { data = await res.json(); break; }
      lastErr = `${res.status} ${await res.text().catch(() => "")}`;
    }
    if (!data) { console.error(`ERROR: failed to list languages: ${lastErr}`); Deno.exit(2); }

    if (jsonMode) {
      console.log(JSON.stringify(data, null, 2));
      return;
    }
    // data is array of {language, name, supports_formality?} or v3 shape — handle both
    const rows = Array.isArray(data) ? data : (data as any).languages ?? [];
    // LLM-friendly table: CODE  NAME  TARGET?  SOURCE?
    for (const r of rows) {
      const code = r.code ?? r.language ?? "";
      const name = r.name ?? code;
      console.log(`${code}\t${name}`);
    }
    console.error(`[${rows.length} languages]`);
  }
  ```
  Help for `deepl list`: `deepl list [--json] [--api-key <key>] [--help]`.
